# Adventure YAML Builder

A lightweight, browser-based tool to draft and validate branching adventure stories. Create nodes on a visual board, edit text and choices, and import or export a YAML structure for your game.

## Features

- Visual node board with drag-and-drop positioning
- Story metadata editor (title and base stats)
- Choice editor with links between nodes
- YAML import and export
- Basic validation feedback

## Getting Started

No build step is required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

## Usage

- Click "Add node" to create a new node.
- Select a node to edit its text and choices.
- Use "Add choice" to create links to other nodes.
- Click "Validate" to check for issues.
- Use "Export YAML" to save the story.
- Use "Import YAML" to load an existing story.

## Notes

- Node 1 is reserved as the start node.
- Node IDs are expected to be between 1 and 400.
